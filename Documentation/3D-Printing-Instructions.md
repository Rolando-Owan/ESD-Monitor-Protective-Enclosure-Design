# 3D Printing Instructions

The enclosure components are designed for FDM 3D printing. Follow the recommendations below to ensure proper fit, appearance, and functionality. 
The recommended print settings were established using the 3D printers available at Hunter Industries. These parameters may require adjustment when using different printers, materials, or slicer configurations. 

## Materials

|         Component       |       Material       |      Color      |
|-------------------------|----------------------|-----------------|
|         Main Case       |     ESD-Safe PETG    |      Black      |
|       Main Case Top     | ESD-Safe PETG / PETG | Black / Yellow  |
| Transparent Front Cover |    Transparent PP    | Natural (Clear) |

## Main Case

- Printing Technology: FDM
- 3D Printer Model: Prusa MK4S
- Nozzle Diameter: 0.60 mm
- Layer Height: 0.30 mm
- Material: Black ESD-Safe PETG
- Infill: 15%
- Wall Count: 3
- Supports: Disabled
- Build Plate Adhesion: Brim

## Main Case Top

- Printing Technology: FDM
- 3D Printer Model: Prusa XL
- Nozzle Diameter: 0.80 mm
- Layer Height: 0.40 mm
- Extruder 1 Material: Black ESD-Safe PETG
- Extruder 2 Material: Yellow PETG
- Infill: 15%
- Wall Count: 3
- Supports: Disabled
- Build Plate Adhesion: Brim
- Add Height Range Modifier: 0.00 - 10.60 mm (Extruder 1), 10.60 - 12.00 mm (Extruder 2)

## Transparent Front Cover

- Printing Technology: FDM
- 3D Printer Model: Prusa MK4S
- Nozzle Diameter: 0.60 mm
- Layer Height: 0.30 mm
- Material: Transparent PP
- Infill: 15%
- Wall Count: 3
- Supports: Disabled
- Build Plate Adhesion: Disabled

## Post-Processing

- Remove all brim material.
- Inspect each printed component for defects.
- Verify proper fit before final assembly.
- Clean the transparent cover before installation to remove fingerprints and debris.
